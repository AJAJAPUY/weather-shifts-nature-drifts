# Weather Shifts, Nature Drifts

A responsive plain HTML, CSS, and JavaScript educational website about climate change, biodiversity, sustainability, environmental science, and technology.

## Run locally

Open `dist/index.html` in any modern browser. The activity progress and streak are saved in that browser using local storage.

The page uses Unsplash image URLs and Google Fonts, so an internet connection is needed for the photographs and custom fonts. The activities themselves run without a server or account. Quiz and true/false rounds show an answer review, while the timed challenge ends after 30 seconds. Daily streaks and the total number of answers reviewed are kept only in the current browser.

The photography, article dates, and editorial staff labels are demonstration content. Replace these with your own licensed images, sources, dates, and team names before submitting or publishing the project.
